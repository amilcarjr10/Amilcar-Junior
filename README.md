## Como documento os laboratórios

Cada projeto segue um fluxo próximo ao utilizado em operações profissionais:

1. Contexto e objetivo do cenário.
2. Descrição do ambiente e das ferramentas.
3. Evidências técnicas e capturas relevantes.
4. Diagnóstico e raciocínio utilizado.
5. Ação executada e resultado obtido.
6. Validação, recomendações e lições aprendidas.

Essa estrutura permite avaliar não somente o resultado, mas também minha capacidade de investigar, comunicar e documentar uma atividade técnica.
