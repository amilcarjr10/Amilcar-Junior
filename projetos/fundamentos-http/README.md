# Fundamentos de HTTP

Laboratório técnico sobre HTTP e HTTPS, anatomia de URLs, requisições e respostas, métodos, códigos de status, cabeçalhos e cookies.

## Objetivo

Compreender o funcionamento da comunicação web no modelo cliente-servidor e interpretar os elementos presentes em uma requisição e em uma resposta HTTP. O projeto conecta os fundamentos do protocolo às atividades de troubleshooting, análise de tráfego e segurança de aplicações web.

## Atividades realizadas

- Comparação entre HTTP e HTTPS, incluindo portas padrão, criptografia e validação do servidor.
- Identificação dos componentes de uma URL, como esquema, host, porta, caminho, parâmetros e fragmento.
- Análise da estrutura de requisições e respostas HTTP.
- Estudo dos métodos **GET**, **POST**, **PUT** e **DELETE**.
- Interpretação de códigos de status, cabeçalhos e cookies.
- Execução de exercícios práticos com consultas GET, parâmetros de URL, envio de formulário de login, atualização e exclusão de recursos.
- Relacionamento dos conceitos com ferramentas de segurança, proxies, WAF, logs e investigação de requisições suspeitas.

## Ferramenta e cenário

O relatório foi desenvolvido na **plataforma TryHackMe**, em exercícios práticos de fundamentos de HTTP e HTTPS voltados à compreensão do tráfego e das interações entre clientes e servidores web.

## Competências demonstradas

**HTTP/HTTPS**, URLs, requisições e respostas, métodos HTTP, códigos de status, cabeçalhos, cookies, modelo cliente-servidor, análise de tráfego web e fundamentos de segurança de aplicações.
