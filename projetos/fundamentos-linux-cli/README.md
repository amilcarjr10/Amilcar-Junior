# Fundamentos de Linux via Linha de Comando

Relatório técnico sobre navegação no sistema de arquivos, busca de arquivos e coleta de informações do sistema por meio da linha de comando Linux.

## Objetivo

Desenvolver segurança e autonomia para operar um ambiente Linux pela CLI, praticando tarefas essenciais de suporte e operações cibernéticas.

## Atividades realizadas

- Compreensão do terminal Linux e de sua importância em operações de tecnologia.
- Navegação pelo sistema de arquivos usando comandos básicos.
- Localização de arquivos com o comando `find`.
- Coleta de informações do sistema e consolidação dos resultados.
- Registro dos principais comandos aprendidos durante o laboratório.

## Ferramenta e cenário

O exercício simulou o primeiro dia de atuação como engenheiro de suporte em uma equipe de operações cibernéticas e foi baseado no módulo de Fundamentos de Linux da TryHackMe.

## Competências demonstradas

**Linux**, linha de comando, navegação de diretórios, busca com `find`, coleta de informações do sistema, suporte técnico e documentação operacional.
