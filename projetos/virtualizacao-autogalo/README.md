# Administração de Ambiente Virtualizado — AutoGalo

Relatório técnico de um laboratório prático de administração de infraestrutura virtualizada, desenvolvido em um cenário corporativo fictício da AutoGalo.

## Objetivo

Aplicar um fluxo real de operação de um ambiente virtualizado, passando pelo diagnóstico de uma falha de serviço, pelo provisionamento de uma nova máquina virtual e pela análise da capacidade dos hosts físicos.

## Atividades realizadas

- Diagnóstico e correção de uma falha crítica no servidor de e-mail `Mail-SERVER`.
- Provisionamento de uma nova máquina virtual para apoiar o site da equipe de Marketing.
- Monitoramento do uso de hardware dos hosts físicos.
- Identificação de riscos de capacidade e registro das decisões técnicas.

## Ferramenta e cenário

O laboratório foi realizado com o **Virtualization Manager**, plataforma utilizada para centralizar o status dos hosts físicos e das máquinas virtuais. O exercício foi baseado no módulo de Virtualização da TryHackMe.

## Competências demonstradas

**Virtualização**, administração de máquinas virtuais, troubleshooting, monitoramento de infraestrutura, análise de capacidade e documentação técnica.
