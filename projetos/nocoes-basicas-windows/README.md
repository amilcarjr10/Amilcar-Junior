# Noções Básicas do Windows

Relatório técnico sobre a integração de um novo funcionário em uma estação Windows, abordando interface, arquivos, aplicativos e segurança.

## Objetivo

Vivenciar as tarefas iniciais de uso e administração de uma estação Windows em um ambiente corporativo, consolidando conhecimentos fundamentais para suporte e operações de tecnologia.

## Atividades realizadas

- Navegação pela área de trabalho, barra de tarefas e menu Iniciar.
- Compreensão de contas de usuário e do processo de autenticação.
- Uso do Explorador de Arquivos para localizar pastas e interpretar caminhos.
- Verificação das configurações do sistema.
- Instalação e desinstalação de um aplicativo corporativo.
- Uso do Gerenciador de Tarefas e da Segurança do Windows para monitoramento e proteção.

## Ferramenta e cenário

O laboratório simulou o primeiro dia de trabalho de um funcionário no ambiente **Windows Server 2019 Datacenter**, com base no módulo de Noções Básicas do Windows da TryHackMe.

## Competências demonstradas

**Windows**, onboarding técnico, gerenciamento de contas, sistema de arquivos, aplicativos, monitoramento de desempenho e fundamentos de segurança.
