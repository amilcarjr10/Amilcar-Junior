# Projetos técnicos

Esta pasta concentra os projetos práticos do portfólio. Cada projeto deve ficar em um diretório próprio e conter, no mínimo, um `README.md` descritivo e os arquivos de apoio relacionados.

## Estrutura recomendada

```text
projetos/
└── nome-curto-do-projeto/
    ├── README.md
    ├── relatorio-nome-do-projeto.pdf
    └── assets/
        └── imagens-ou-evidencias.ext
```

## Convenções

Use nomes de diretórios em minúsculas, sem espaços e separados por hífens. Mantenha o README de cada projeto focado em seu objetivo, contexto, atividades realizadas, competências praticadas e link para a documentação completa.

| Elemento | Padrão recomendado |
| --- | --- |
| Diretório | `nome-curto-do-projeto/` |
| Documento principal | `README.md` |
| Relatório | `relatorio-nome-do-projeto.pdf` |
| Evidências visuais | `assets/` dentro do projeto |
| Link na página principal | Adicionar uma linha à tabela de projetos do README raiz |

## Modelo de README

```markdown
# Nome do projeto

Resumo objetivo do projeto e do cenário analisado.

## Objetivo

Descreva o problema, laboratório ou competência que foi praticado.

## Atividades realizadas

Explique as principais etapas executadas e as ferramentas utilizadas.

## Competências demonstradas

Liste as tecnologias, conceitos e procedimentos aplicados.

## Documentação

- Relatório técnico: `relatorio-nome-do-projeto.pdf`
```

Depois de criar um novo projeto, atualize também o [`README.md` principal](../README.md) para que ele apareça no catálogo do portfólio.
